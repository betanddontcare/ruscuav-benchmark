# Real-GIS worlds

This directory contains AOI metadata and the frozen pipeline configuration for Vienna and Warsaw. Processed real-GIS NPZ worlds are intentionally absent. Regenerate them with the real-GIS blocks in `source_code/top_uav_submission_pipeline.py` or the legacy/full Colab export, using `real_gis_pipeline_v0.yaml` and the archived metadata.

Cross-AOI comparisons in the paper use the explicit-footway interpretation. The conservative road-buffer pedestrian proxy is retained only as a budget-calibration diagnostic.
